ReachPanel Companion

Android tablet app that drives the Windows ReachPanel host — keyboard, trackpad, numpad, and dictation over your local network.

Download APK

Tablets are required. Phone-sized devices can install this APK but are blocked when the app launches. First install may require allowing installs from this browser (unknown apps). This is a pre-release APK; Expo Go will not work for caregivers.

Hosted on Vercel (private GitHub repo). APK served from Vercel Blob at a stable URL. CI replaces the download link placeholder before deploy.
