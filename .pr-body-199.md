## Summary

- Add a shared always-on-top `dictation-overlay` window that shows the recording visualizer at bottom-center while listening/processing
- Drive show/hide from global `dictationState` so every mode (Normal, Mini, Teaching, and future Mic mode) reuses one overlay without stealing focus or disabling main
- Remove the inline keyboard visualizer; exclude the overlay from live input capture

## Commit message

`feat: show shared dictation overlay at screen bottom-center`

## Related issue

Fixes #199

## Accessibility impact

Dictation feedback stays visible even when the keyboard is collapsed to FABs (Mini mode). Overlay is non-focusable so dictated text still lands in the user's target field.
