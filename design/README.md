# ReachPanel branding

## Provenance

- **`reachpanel-logo.svg`** — owner-made master logo (Nikos / pountzas), supplied on [issue #175](https://github.com/pountzas/reach-Panel/issues/175) (2026-10). 1024×1024 viewBox, transparent background.
- **`app-icon.png`** — 1024×1024 RGBA raster of the SVG, generated by the script below. Source for Tauri icon regeneration.

## Regenerate icons

From the repo root (requires `npm install` so `sharp` and `@tauri-apps/cli` are available):

```bash
# Rasterize SVG → design/app-icon.png and companion launcher assets
node scripts/generate-brand-icons.mjs

# Regenerate src-tauri/icons/ from the master PNG
npm run tauri -- icon design/app-icon.png
```

After `tauri icon`, Android/iOS outputs and `icon.icns` are git-ignored; commit only the Windows sizes at the top level of `src-tauri/icons/`.

Do not hand-edit individual sizes under `src-tauri/icons/` unless fixing a specific platform glitch. After a rebrand, replace `design/reachpanel-logo.svg`, re-run both commands, and commit the generated files.

## Surfaces

| Surface | Source |
| --- | --- |
| Windows exe / Start / MSI | `src-tauri/icons/` via `tauri.conf.json` → `bundle.icon` |
| Windows taskbar button | same `icon.ico` embedded resource; app sets `WM_SETICON` `ICON_BIG` at startup (wry only sets `ICON_SMALL`) |
| NSIS installer (`setup.exe`) | `src-tauri/icons/icon.ico` via `tauri.conf.json` → `bundle.windows.nsis.installerIcon` |
| Collapsed Mode-menu FAB | imports `design/reachpanel-logo.svg` in `src/components/layout/CollapsedFab.tsx` |
| Android companion launcher | `companion/assets/icon.png` + adaptive icon PNGs |
